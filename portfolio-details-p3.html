Descripción del Proyecto:

Proyecto de Punto de venta creado con Java el cual permitirá a los comerciantes y empleados de una empresa, registrar productos, clientes, proveedores y procesar ventas de manera rápida y precisa. Incluye funciones como la gestión de inventario, la generación de facturas, cotizaciones y recibos, la administración de clientes y la generación de informes gráficos sobre las ventas.

Características Clave

Autenticación de usuarios con roles

Inicio de sesión mediante credenciales validadas en la base de datos.

Los usuarios tienen roles definidos (empleado o administrador), que determinan los permisos dentro del sistema.

Gestión de clientes y proveedores

Registra y administra datos completos de clientes y proveedores, permitiendo su uso directo durante la generación de ventas o reposición de productos.

Registro y control de ventas en base de datos

Cada venta realizada se guarda en phpMyAdmin, con detalles como productos, cantidades, fecha, total y cliente. Esto permite consultas históricas y trazabilidad del flujo de caja.

Interfaz de administración de usuarios

Funcionalidad para que administradores registren, editen o eliminen usuarios, facilitando el control de acceso al sistema y la gestión del personal.
